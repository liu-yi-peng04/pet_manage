# 宠物急救常识与应急预案

紧急情况下的正确处理能争取宝贵的救治时间。**以下内容为院前急救参考，处理完应尽快送往宠物医院。**

## 一、中毒急救

**常见毒物**：巧克力、葡萄、洋葱、木糖醇、老鼠药、百合花（猫）、人用药物（退烧药、感冒药）、清洁剂、杀虫剂。

处理步骤：
1. **立即移除毒物**，保存毒物包装/样本带去医院。
2. **不要自行催吐**（催吐有误吸和腐蚀风险，是否催吐由兽医决定，且已腐蚀食管时催吐更危险）。
3. 立刻电话联系宠物医院说明毒物和体重，按医嘱前往。
4. 若宠物已昏迷或抽搐，保持呼吸道通畅，侧卧，立即送医。

## 二、中暑急救

中暑高发于夏季密闭车内、长时间暴晒、剧烈运动。猫狗汗腺不发达，散热能力差。

症状：大口喘气、流涎、牙龈鲜红/发紫、体温>40℃、走路不稳、呕吐。

处理：
1. **立即离开热源**，移至阴凉通风处。
2. 用常温（勿用冰水）湿润毛巾敷腋下、腹股沟、爪垫，或用风扇吹风。
3. 少量多次喂常温饮水，不要强行灌水。
4. 体温降至 39.4℃ 左右即可停降温，**避免过度降温致休克**。
5. 症状明显时送医——中暑可引发多器官衰竭，死亡率高。

## 三、外伤出血急救

1. **直接压迫止血**：用干净纱布/毛巾按压伤口 5-10 分钟，不要频繁掀开看。
2. 四肢远端出血可结扎（用布条）于伤口近心端，每 15 分钟松一次，防止组织坏死。
3. 小伤口清洁后用碘伏消毒（猫狗可用），深伤口或咬伤需就医（可能需抗生素和破伤风处理）。
4. 出血不止、大动脉出血、或腹部穿透伤，立即送急诊。

## 四、骨折处理

1. **不要尝试复位**，不要随意搬动伤肢。
2. 用硬板/杂志临时固定（夹板超过上下两个关节），缠布固定。
3. 搬运时保持宠物躯干平稳，用毯子兜住，避免二次损伤。
4. 立即就医拍片确诊。

## 五、窒息/异物卡喉

症状：剧烈咳嗽、抓嘴、呼吸困难、牙龈发紫。

处理：
1. 检查口腔，**手指盲目掏取可能把异物推更深**，仅在你看见并能安全取出时操作。
2. 小型犬猫可尝试海姆立克：抱起使其头朝下，冲击胸廓下缘。
3. 大型犬：站在背后，双手环抱其腹部向上快速冲击。
4. 无效且窒息明显，立即送急诊。

## 六、溺水

1. 从水中救出后，头低脚高放置，清除口鼻异物。
2. 若无呼吸，进行人工呼吸（口对鼻吹气，犬猫嘴型不同，吹气使胸廓可见起伏即可）。
3. 无心跳时进行胸外按压（侧卧，按压心脏区域，频率 100-120/分钟）。
4. 即使复苏成功也务必送医检查（吸入性肺炎风险）。

## 七、抽搐/癫痫

1. 保持环境安静、移开周围危险物品。
2. **不要按住宠物、不要把手放进它嘴里**（不会咬断舌头，反而会被咬伤）。
3. 记录抽搐时间，关上灯和声音。
4. 抽搐超过 3-5 分钟或连续发作，立即送急诊。

## 八、猫尿闭（致命急症）

症状：频繁蹲猫砂盆无尿、痛苦嚎叫、舔舐腹部、呕吐。

**这是急诊**：超过 24 小时可致急性肾衰和膀胱破裂。立即送医导尿，不要在家尝试按摩或喂药。

## 九、急救箱常备物品

- 纱布卷、医用胶带、碘伏棉签
- 宠物专用止血粉/云南白药（外敷）
- 电子体温计（肛温）
- 生理盐水、注射器（喂水用）
- 伊丽莎白圈（防舔咬伤口）
- 宠物医院 24 小时急诊电话（写下来贴冰箱）

## 重要提醒

- 急救不能替代治疗，稳定情况后**第一时间送医**。
- 提前确认附近 24 小时急诊宠物医院，收藏联系方式。
- 给宠物做基础体检，了解正常体温（犬猫 38-39.2℃）、心率、呼吸频率，异常才能早发现。
