# 犬猫营养与喂食指南

正确的饮食是宠物健康的基石。喂错食物轻则肥胖，重则危及生命。

## 一、喂食类型选择

| 类型 | 优点 | 缺点 |
|---|---|---|
| 干粮（膨化粮） | 便宜、易储存、有洁齿效果 | 水分少，需保证饮水 |
| 湿粮/罐头 | 水分足、适口性好 | 价格高，开封后易变质 |
| 冻干/生骨肉 | 营养保留好 | 价格高，生食有细菌风险，需专业指导 |
| 处方粮 | 针对疾病（肾衰、胰腺炎等） | 必须兽医开具，不可自行长期使用 |

## 二、每日喂食量参考

喂食量以包装袋推荐为基准，按体重、运动量和体况调整：

- **犬**：成年犬每日干粮约为体重的 2%-3%（分 2 餐）；幼犬按体重 4%-6%（分 3-4 餐）。
- **猫**：成年猫每日约 40-60 千卡/kg 体重；罐头按包装建议。

原则：**七分饱 + 定时定量**，肥胖是犬猫最常见的营养性疾病。

## 三、喂食频次

| 阶段 | 频次 |
|---|---|
| 幼犬/幼猫（<6月龄） | 每日 3-4 餐 |
| 6-12 月龄 | 每日 2-3 餐 |
| 成年 | 每日 2 餐（猫可自由采食但需控量） |
| 老年 | 每日 2-3 餐，少量多次 |

## 四、禁忌食物（严格禁止）

- **巧克力/可可**：含可可碱，可致中毒死亡。
- **洋葱/大蒜/韭菜**：破坏红细胞导致溶血性贫血。
- **葡萄/葡萄干**：可致急性肾衰竭，猫犬均不可食。
- **木糖醇**（无糖口香糖等）：极低剂量即可致低血糖、肝衰竭。
- **酒精**：极小量即中毒。
- **咖啡/茶**：咖啡因中毒。
- **生鸡蛋清**：影响生物素吸收；煮熟的蛋可以。
- **骨头**：尤其禽类煮熟的骨头，易碎裂划伤消化道。
- **大量肝脏**：维生素 A 中毒（少量每周一两次可以）。

## 五、猫咪特殊要求

- 猫是**纯肉食动物**，需牛磺酸（缺乏致失明、心脏病），狗粮不能替代猫粮。
- 猫对蛋白质需求远高于狗。
- 猫咪不爱喝水易患泌尿疾病，建议湿粮+流动水（宠物饮水机）鼓励饮水。

## 六、换粮方法

突然换粮易致肠胃不适，需 7-10 天过渡：
- 第 1-2 天：新粮 25% + 旧粮 75%
- 第 3-4 天：各 50%
- 第 5-6 天：新粮 75% + 旧粮 25%
- 第 7 天起：全换新粮

## 七、饮水和补充剂

- 保证全天清洁饮水，每日更换。
- 市售"营养膏""补钙粉"多数宠物不需要，盲目补充反而有害。
- 鱼油（Omega-3）对皮肤毛发有益，按剂量补充。
- 益生菌可在肠胃不适时短期使用。

## 重要提醒

- 喂食量不是固定公式，观察体况：能摸到肋骨但看不见，是理想体态。
- 突然食欲废绝超 24 小时（猫更短）需尽快就医。
- 保持体重稳定是延长宠物寿命的关键因素之一。
