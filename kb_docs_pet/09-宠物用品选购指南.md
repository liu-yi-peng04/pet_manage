# 宠物用品选购指南

选对用品关乎宠物的舒适与安全。本指南覆盖笼具、玩具、牵引、猫砂等高频品类。

## 一、宠物笼子/航空箱选购

### 尺寸标准（关键）
**笼子长度 ≥ 宠物身长（鼻尖到尾根）× 1.5，高度 ≥ 宠物站立肩高**，让宠物能站立、转身、趴下。

| 宠物 | 建议笼内尺寸（长×宽×高 cm） |
|---|---|
| 玩具型犬（<4kg，如泰迪） | 60×45×50 以上 |
| 小型犬（4-10kg，如柯基、博美） | 75×50×55 以上 |
| 中型犬（10-25kg，如边牧、柴犬） | 90×60×65 以上 |
| 大型犬（25-40kg，如金毛、德牧） | 110×70×75 以上 |
| 猫（普通家猫 3-6kg） | 60×45×50 以上 |

### 材质选择
- **金属笼**：通风好、耐咬、易清洁，适合日常和运输；注意底部栅栏间距勿夹脚，可铺软垫。
- **航空箱（塑料）**：密闭有安全感，符合航司规定，适合出差、应激场景；注意尺寸符合航空要求。
- **软包/布笼**：仅适合训练或临时使用，不耐咬。

### 使用要点
- 笼子应是"安全屋"不是"监狱"：放软垫、水壶、玩具，不用于惩罚。
- 外出时笼子内放带主人气味的衣物，减少应激。
- 航空箱提前在家训练适应（开着门、放零食），避免临时上车应激。

## 二、宠物玩具选购

### 按材质安全分级
| 玩具 | 适合 | 注意 |
|---|---|---|
| 橡胶漏食球/耐咬棒 | 中大型犬、啃咬型 | 选择大于口腔的尺寸防吞咽 |
| 绳结玩具 | 互动拔河 | 绳线脱落时及时更换，防误食 |
| 逗猫棒 | 猫 | 用完收好，防猫误吞羽毛 |
| 电动/益智玩具 | 精力旺盛犬猫 | 注意电池仓安全 |
| 毛绒玩具 | 依恋型宠物 | 缝线开裂后丢弃，防棉絮误食 |
| **网球/硬骨** | ❌ 不推荐 | 网球磨损牙釉质，硬骨（牛骨等）易致牙齿断裂 |

### 通用安全原则
1. 玩具尺寸大于宠物喉径（太小球类易窒息）。
2. 咬碎、脱线、掉渣即换，防误食异物。
3. 猫玩具每周更换轮换，保持新鲜感。
4. 橡皮筋、塑料包装袋、毛线等生活垃圾对宠物是致命诱惑，务必收纳。

## 三、牵引绳与项圈

| 类型 | 适合 | 注意 |
|---|---|---|
| 普通项圈 | 温顺小型犬 | 过紧勒喉，两指可插入为宜 |
| **胸背带（推荐）** | 多数犬 | 分散压力，防爆冲伤气管，推荐日常使用 |
| 伸缩牵引绳 | 空旷区域 | 闹市区禁用，易缠绕伤人 |
| P链/电击项圈 | ❌ 不推荐 | 易致气管和颈椎损伤，训练应使用正向方法 |

- 尺码：胸背带以能插入两指为宜，太松易挣脱。
- 猫外出建议专用胸背带+牵引绳（猫项圈有勒死风险，室内建议用安全扣项圈）。

## 四、猫砂与猫砂盆

### 猫砂类型对比
| 类型 | 优点 | 缺点 |
|---|---|---|
| 膨润土砂 | 结团好、便宜 | 粉尘大 |
| 豆腐砂 | 可冲马桶、低尘 | 结团略差 |
| 混合砂 | 结团+低尘平衡 | 价格略高 |
| 松木砂/水晶砂 | 吸味强 | 部分猫不喜欢脚感 |

### 猫砂盆
- 数量：**猫的数量 + 1**。
- 大小：至少猫身长 1.5 倍，封闭式盆要注意通风和气味（部分猫不喜欢封闭式）。
- 摆放：安静、避开食盆水盆、人少经过处。

## 五、其他高频用品

- **食盆**：不锈钢/陶瓷优先，塑料易滋生细菌且部分宠物过敏；水盆和食盆分开。
- **饮水机**：流动水能显著增加猫饮水量，过滤棉定期更换。
- **梳子**：短毛用橡胶梳，长毛用针梳+排梳；每周 2-3 次。
- **指甲剪**：宠物专用剪刀式，注意避开血线；每月 1-2 次。
- **伊丽莎白圈**：术后/皮肤病治疗必备，买软边可调节款。
- **宠物床**：按体型选，可拆洗面料优先。

## 重要提醒

- 无论买什么用品，**安全永远优先于颜值**：尺寸合适、材质无毒、无小零件。
- 网购用品先看该宠物个体情况（体型、咬合力、年龄）再下单，避免买错尺寸浪费。
- 出行航空/自驾请先确认航司/酒店的宠物规定和笼具标准。
